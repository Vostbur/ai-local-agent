# Контекст проекта: ai-local-agent

Мы продолжаем разработку проекта `ai-local-agent`. Это локальный ИИ-агент с веб-интерфейсом, работающий в изолированной среде без доступа к интернету. 

**Стек:** Python, FastAPI, HTMX, Alpine.js, Tailwind CSS, Ollama (модель qwen2.5-7b-agent). ОС: Windows.

## 🏗 Текущее состояние (что уже сделано)
- **Веб-интерфейс:** Работает вкладка «Агент», сохраняется история чата в `localStorage`.
- **Офлайн-режим:** Все CDN (Tailwind, HTMX, Alpine, marked, DOMPurify) заменены на локальные файлы из `/static/`. Шрифты Google заменены на системные.
- **SSE-стриминг:** Исправлен парсинг. Бэкенд отдает валидный JSON (через `json.dumps`), клиент его корректно парсит.
- **Переподключение (Важно!):** Если переключиться на другую вкладку во время работы агента, при возврате происходит переподключение к потоку. Бэкенд использует `TaskState` (список событий) вместо `asyncio.Queue`, чтобы клиент мог догнать поток.
- **Таймер:** Не сбрасывается при переключении вкладок (время старта хранится в `localStorage`).
- **UI:** Поле ввода на всю ширину (как в ChatGPT), кнопки-подсказки внизу, поддержка `Enter` (отправка) и `Shift+Enter` (перенос строки). Приветствие закреплено.
- **Чистота:** Убраны 404 ошибки (пустой favicon, удален sourceMappingURL).
- **Утечка памяти:** Добавлен `lifespan` cleanup loop в `web/app.py` для автоматической очистки завершённых задач (через 5 минут) и активных (через 2 часа).
- **JSON-сериализация:** `tool_results` в `orchestrator.py` теперь корректно сериализуются через `_serialize_tool_result()` — Path, dict, list конвертируются в JSON-совместимый формат.
- **Фильтр корзины:** Заменена хрупкая проверка `"trash" not in path.parts` на явную проверку через `is_relative_to(trash_dir)` во всех инструментах заметок.
- **Асинхронный LLM:** `OllamaLLM` поддерживает `chat_async()` через `httpx.AsyncClient` с fallback на `asyncio.to_thread()`. `Orchestrator` имеет `run_async()` с поддержкой отмены.
- **Отмена задач:** Добавлен эндпоинт `POST /cancel/{task_id}` и кнопка отмены в UI (иконка квадрата/стопа).

## 🛑 Грабли (на которые мы уже наступили)
- **ImportError:** Нельзя смешивать импорты `from src.agent...` и `from agent...` в одном файле. Придерживаемся единого префикса `src.agent`.
- **HTMX и DOM:** HTMX уничтожает DOM при смене вкладок. Все важные состояния (task_id, время старта) должны храниться в `localStorage`.
- **Сериализация JSON:** `tool_results` в `orchestrator.py` имел тип `list[str]`, из-за чего `None` и одинарные кавычки ломали JSON. **Закрыто:** добавлена функция `_serialize_tool_result()` для рекурсивной конвертации в JSON-совместимый формат.
- **Утечка памяти в TaskState:** `TaskState` в `web/app.py` накапливался бесконечно, если клиент отключался до завершения задачи. **Закрыто:** добавлен `lifespan` cleanup loop с TTL (5 минут для завершённых, 2 часа для активных).
- **Хрупкий фильтр корзины:** Проверка `"trash" not in path.parts` работала случайно: если корзина была вне `notes_dir`, фильтр был избыточен; если внутри — мог пропустить файлы в подпапках с именем `trash`. **Закрыто:** заменено на явную проверку через `is_relative_to(trash_dir)`.
- **Синхронный LLM в async FastAPI:** `requests.post()` в `OllamaLLM.chat()` блокировал event loop FastAPI. **Закрыто:** добавлен `chat_async()` через `httpx.AsyncClient` и `run_async()` в `Orchestrator`.
- **Alpine.js и inline x-data:** Большие inline-объекты в `x-data` ломают парсинг Alpine.js. **Решение:** выносить логику в `Alpine.data()` с регистрацией компонента.

## 🎯 Ближайшие задачи (Roadmap)
1. **T37: Контекст диалога.** Агент не помнит предыдущие сообщения. Нужно реализовать передачу истории (варианты: через `localStorage` на фронте или через `session_id` на бэке).
2. **T39: Кэширование BM25 индекса.** BM25Index пересоздаётся при каждом запросе, что замедляет первый поиск. Решение: сериализовать на диск и загружать при старте.
3. **T40: Стабильный call_key.** `call_key` формируется через `str()` от аргументов, что даёт нестабильное представление для Path и dict. Решение: использовать `json.dumps(arguments, sort_keys=True, default=str)`.
4. **Этап B (UI):** Прямой API и вкладка «Заметки» в UI (таблица, редактирование, удаление, категории).
5. **Этап C:** Управление документами и инкрементная индексация.

Пожалуйста, ознакомься с этим контекстом. Если готов, напиши «Контекст принят» и жди моей первой задачи.
