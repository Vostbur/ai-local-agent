Этот файл предназначен для быстрого погружения ИИ-ассистента (ChatGPT, Claude, DeepSeek, Cline) в контекст проекта `ai-local-agent`. Скопируйте содержимое блока ниже в начало нового диалога, чтобы продолжить разработку без потери истории и накопленных правил.

# Контекст проекта: ai-local-agent

Мы продолжаем разработку проекта `ai-local-agent`. Это локальный ИИ-агент с веб-интерфейсом, работающий в изолированной среде без доступа к интернету. 

**Стек:** Python, FastAPI, HTMX, Alpine.js, Tailwind CSS, Ollama (модель qwen2.5-7b-agent). ОС: Windows.

## ⚠️ Правила общения (строго соблюдать)
1. **Полные тексты файлов:** Никогда не пиши «замени строку X на Y». При изменении файла всегда приводи его полный текст.
2. **Команды для Cline:** Каждое действие оформляй как явную команду для ИИ-ассистента Cline (например: `Cline, создай или перезапиши файл <путь> со следующим содержимым:`).
3. **Коммиты:** После каждого завершенного шага или логического блока давай готовую команду для коммита в git с осмысленным сообщением (`git add ...`, `git commit -m "..."`).
4. **Точные пути:** Учитывай текущую структуру (например, `src/agent/web/dashboard/templates/views/agent.html`). Не используй сокращенные или неверные пути.
5. **Никакого CDN:** Проект работает офлайн. Все библиотеки должны лежать локально в папке `static/`.
6. **Без лишней воды:** Если я прошу объяснить концепцию — объясняй текстом, не пиши код. Если прошу код — давай полный файл.
7. **По одному недостатку за раз:** Не переходить к следующему недостатку без явного подтверждения пользователя.
8. **Тесты к каждому изменению:** Если изменение можно покрыть тестами — писать их в том же блоке и давать команду запуска.

## 🏗 Текущее состояние (что уже сделано)
- **Веб-интерфейс:** Работает вкладка «Агент», сохраняется история чата в `localStorage`.
- **Офлайн-режим:** Все CDN (Tailwind, HTMX, Alpine, marked, DOMPurify) заменены на локальные файлы из `/static/`. Шрифты Google заменены на системные.
- **SSE-стриминг:** Исправлен парсинг. Бэкенд отдает валидный JSON (через `json.dumps`), клиент его корректно парсит.
- **Переподключение (Важно!):** Если переключиться на другую вкладку во время работы агента, при возврате происходит переподключение к потоку. Бэкенд использует `TaskState` (список событий) вместо `asyncio.Queue`, чтобы клиент мог догнать поток.
- **Таймер:** Не сбрасывается при переключении вкладок (время старта хранится в `localStorage`).
- **UI:** Поле ввода на всю ширину (как в ChatGPT), кнопки-подсказки внизу, поддержка `Enter` (отправка) и `Shift+Enter` (перенос строки). Приветствие закреплено.
- **Чистота:** Убраны 404 ошибки (пустой favicon, удален sourceMappingURL).
- **Утечка памяти:** `lifespan` cleanup loop в `web/app.py` очищает завершённые задачи через 5 минут и брошенные через 2 часа.
- **JSON-сериализация:** `tool_results` сериализуются через `_serialize_tool_result()` (Path → POSIX-строки, dict/list рекурсивно, `None` → `null`).
- **Фильтр корзины:** явная проверка `is_relative_to(trash_dir)` во всех инструментах заметок вместо проверки подстроки.
- **Асинхронность:** `OllamaLLM.chat_async()` (httpx + fallback `to_thread`), `Orchestrator.run_async()`, `AgentService.ask_async/ask_plain_async`, веб на `asyncio.create_task`; эндпоинт `POST /cancel/{task_id}`; кнопка отмены в UI (иконка квадрата, цвет как у отправки).
- **Память диалога (T37):** веб и CLI передают историю в `/ask`; бэкенд санует её (`sanitize_history`: роли только user/assistant, ≤10 сообщений, бюджет 4000 символов); Pydantic отклоняет чужие роли кодом 422.
- **Кэш BM25 (T39):** `data/index/bm25.json` с манифестом содержимого чанков; загрузка без перетокенизации; тихий фолбэк на пересборку при несовпадении.
- **Стабильный call_key (T40):** канонический JSON аргументов вместо `str()`.

## 🛑 Грабли (на которые мы уже наступили)
- **ImportError:** Нельзя смешивать импорты `from src.agent...` и `from agent...` в одном файле. Придерживаемся единого префикса `src.agent`.
- **HTMX и DOM:** HTMX уничтожает DOM при смене вкладок. Все важные состояния (task_id, время старта) должны храниться в `localStorage`.
- **Сериализация JSON:** `tool_results` имел тип `list[str]`, из-за чего `None` и одинарные кавычки ломали JSON. **Закрыто:** `_serialize_tool_result()`.
- **Утечка памяти в TaskState:** накапливался бесконечно при отключении клиента. **Закрыто:** `lifespan` cleanup loop с TTL.
- **Хрупкий фильтр корзины:** `"trash" not in path.parts`. **Закрыто:** `is_relative_to(trash_dir)`.
- **Синхронный LLM в async FastAPI:** `requests.post()` блокировал event loop. **Закрыто:** `chat_async()` + `run_async()`.
- **Alpine.js и inline x-data:** Большие inline-объекты в `x-data` ломают парсинг Alpine.js и рендерятся текстом. **Решение:** выносить логику в отдельный `<script>` (IIFE с `window.*`-функциями, как в текущем `agent.html`), не в inline-атрибуты.
- **T41 (ОТКРЫТО):** после `POST /index` запущенный веб-сервер держит старый `VectorStore` в замыкании `_RagContext` и ищет по старому индексу до перезапуска. **Обход:** перезапускать `python -m agent web` после переиндексации; чиним вместе с этапом C.
- **Моки и сигнатуры:** при изменении сигнатур `ask/ask_async/run/run_async` моки в тестах падают `TypeError` внутри async-генераторов, и ошибка проявляется как `internal: ...` в `FinalEvent`, а не сразу. **Правило:** тем же коммитом grep-ить и править моки в `tests/`.
- **История с клиента — недоверенные данные:** любой клиентский «контекст» валидируется на входе (`sanitize_history`, Pydantic `Literal`), а не в месте использования.
- **Дисковый кэш без инвалидации бесполезен:** у `bm25.json` есть манифест содержимого, `format_version` и тихий фолбэк на пересчёт; ничего из этого нельзя убирать.
