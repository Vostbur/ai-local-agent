### C2. Стемминг: `stem.py` (префикс 5 символов), не `pymorphy3`
Три попытки были:
- `query[:-2]` в `_search.py` — заменён на общий `stem()` (T28).
- BM25 без стемминга — заменён на `stem()` (7.1.4).
- `pymorphy3` (лемматизация) — отклонён: тяжёлая (~10 МБ + словари) и **не сводит** глагол и существительное к одному стему («установить» и «установка» имеют разные леммы). Префикс 5 символов решает нашу задачу точнее.

**Ограничение:** «банк» (4) и «банка» (5) не сводятся к одному стему — короткие слова не трогаются. Для поиска заметок это приемлемо.

### C5. Hybrid search доминируется vector на семантически близких запросах
BM25 в изоляции находит «Установка с нуля» по «Как установить агента?» со score 8.766. `search_hybrid` возвращает «Как понять, что агент выбрал…» — `mpnet-base-v2` ставит этот чанк vector top-1, «Установка» не в vector top-10. RRF использует ранги, не score — преимущество BM25 теряется.

**Причина:** семантика `mpnet`, не размер корпуса (проверено на 94 и 3116 чанках).

**Что работает:** «требования к оперативной памяти», «16 ГБ», «как настроить OSPF» — находятся корректно.

**Обход:** уточнять запрос («по названию раздела», «что в документации про установку»).
**Возможные решения (отложить):** e5-small с префиксами `query:`/`passage:`, cross-encoder реранкер, взвешенный RRF с логарифмом BM25-score.
**Приоритет:** низкий. Не блокер для шага 8 / U5.

### U4. `AgentService` — следующий
**Приоритет:** перед U5.
**Зачем:** `scripts/run_agent._run_one` печатает в stdout через `print`. Для web нужен структурированный поток событий, иначе печать придётся дублировать для CLI / Web / (в будущем) других интерфейсов.
**Что:**
- `src/agent/service.py` — `AgentService(config, logger)`.
- `ask(goal: str) -> AsyncIterator[Event]`.
- `Event` — `StepEvent(step, type, tool_name, count)`, `FinalEvent(OrchestratorResult)`.
- `Orchestrator` получает `on_step: Callable[[int, str], None] | None`, вызывается на каждом шаге.
- `cli.py` переписывается на `AgentService`.
- `ask` (без tools) — отдельный метод или `ask(use_tools=False)`.
- Тесты: `test_service.py` с `FakeLLM`, проверка последовательности событий.
**Закрывает:** C3 частично, T29 (`MaxStepsExceeded` и `unknown type` → `FinalEvent`).
**Почему перед web:** UI должен показывать прогресс («ищу в документах → нашёл 5 → генерирую»), а не висящий курсор 2–4 минуты.

### U5. Веб-интерфейс (FastAPI + SSE + HTMX)
**Приоритет:** после U4.
**Что:**
- `src/agent/web/app.py` — FastAPI.
- `GET /` — HTML: вкладки **Заметки**, **Документы**, **Чат (ask)**, **Фото (в разработке)**.
- `POST /ask` → `task_id`; `GET /stream/{task_id}` → SSE (`StepEvent`/`FinalEvent`).
- `POST /index` — переиндексация с SSE-прогрессом.
- `POST /analyze_image` → `501 Not Implemented` с `{"error": "image analysis not yet implemented", "see": "TASKS.md"}`.
- Вкладка «Фото» — disabled с пометкой «в разработке, см. шаг 8».
- Jinja2 + vanilla `EventSource` (или HTMX). Без React/Vue.
- Запуск: `python -m agent web` (порт 8000, только `localhost`).
**Зависимости:** `fastapi`, `uvicorn`, `jinja2` (~10 МБ) в `requirements.txt` и `pyproject.toml`.
**Почему SSE, а не обычный HTTP:** 7B на CPU отвечает 2–4 минуты, браузер закроет соединение по таймауту. SSE держит соединение, показывает прогресс. Не требует стриминга Ollama — прогресс по шагам оркестратора уже полезен.
**Безопасность:** только `localhost`. Если открывать в локальной сети — предупредить в README. Не выставлять в интернет.
**Не входит:** стриминг токенов (U6), аутентификация, история диалогов, множественные пользователи.

## 📌 Уроки

### Урок: `import pymupdf`, не `import fitz`
`fitz` — старое имя PyMuPDF, deprecated с 1.24. Cline при создании `pdf.py` использовал `import fitz`, тесты — `import pymupdf`. Результат: `FutureWarning` в проде, невидимый в pytest (маскировался `filterwarnings`).

**Правило:** проверять импорты библиотек, которые недавно переименовывались. `Select-String "import fitz"` по `src/` находит за секунды.

### Урок: тесты на «неизвестный X» используют гарантированно неизвестный X
Три раза за сессию тест падал после добавления нового формата, потому что использовал «пока неизвестное» расширение (`.pdf` → `.xyz` в 7.4; `.pdf` → `.xyz` в `test_ignores_unknown_extensions`; потенциально `.docx` в 7.4.1).

**Правило:** тесты на «неизвестный suffix» используют `.xyz`, `.bin`, `.nonexistent` — расширения, которых **никогда** не будет в реестре.

### Урок: few-shot с синтаксисом вызова инструмента ломает routing
Три раза за сессию few-shot с `→ tool_name(...)` в `SYSTEM_PROMPT` ломал routing:
1. 7.2.2, 3B — пустые финалы на 2 вопросах.
2. 7.3, 7B — модель написала `write_document({...})` текстом вместо tool_call.

**Причина:** слабые модели «подражают» формату из примеров как тексту ответа. `→ tool_name(args)` читается как «так пиши ответ».

**Правило:** few-shot — только с описанием последовательности действий («сначала read_document, потом write_document»), без синтаксиса вызова. Тест `test_system_prompt_does_not_contain_write_document_few_shot` страхует.

### Урок: «7B копирует» ≠ «7B виновата»
`read_document` склеивал только `seg.text`, выбрасывая `seg.section`. Модель не видела заголовки `## 1. Введение` — только плоский текст плейсхолдеров. Результат выглядел как «7B копирует шаблон», но на самом деле модель **не видела структуру**.

**Правило:** перед тем как винить модель, проверить в `logs/agent.log`, что именно ушло в `tool_result`. Если данных не хватает — баг в инструменте.

### Урок: «documentation rot» — правки промптов без теста теряются
T26 (замена `extract a short descriptive phrase` на `do NOT invent`) был отмечен `[x]`, но в код не попал — файл `save_note.py` переписывался при T5, T17, правка потерялась. Обнаружено внешним ревью.

**Правило:** любая правка промпта сопровождается тестом на наличие / отсутствие ключевой фразы. 3 строки — дешёво, ловит регресс.

### Урок: дефолты в двух местах — источник багов
`RAGConfig` содержал правильные дефолты (`mpnet`, `400`), а `load_config` — старые (`MiniLM`, `800`). Пользователь без `[rag]` в TOML получал не то, что обещает документация. Исправлено через `RAGConfig()` в `load_config`.

**Правило:** дефолт — в одном месте. `load_config` берёт из датакласса (`rag_defaults = RAGConfig()`), а не хардкодит.
