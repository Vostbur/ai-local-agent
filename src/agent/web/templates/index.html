AI Local Agent локальный веб-интерфейс

Задайте цель агенту. Он может сохранять заметки, искать по документам, читать и создавать файлы. Примеры: Сохрани заметку 'Список покупок' с текстом 'Молоко', Что в документах про OSPF?.


  

  

    
Поиск по корпусу документов (Markdown, TXT, PDF) и переиндексация. Переиндексация занимает 2–5 минут на CPU.

    
    

      
      
    

    

    

  

  

    
Прямой чат с локальной моделью — без инструментов, без SYSTEM_PROMPT. Ответы из pretrained-знаний (могут ошибаться). Для вопросов про проект используйте вкладку «Агент».
