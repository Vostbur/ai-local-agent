## Известные проблемы и наблюдения

### Модель qwen2.5-3b: нестабильный tool calling
**Дата:** 2026-10-25

**Симптомы:**
- Модель зацикливается на повторных вызовах одного и того же инструмента (3 вызова `save_note` вместо одного).
- Генерирует бессмысленный контент вместо осмысленного текста (например, `Имя срАгоетство возвания`).
- Файлы сохраняются с суффиксами `_1.md`, `_2.md` из-за повторных вызовов.

**Причина:** Модель `qwen2.5-3b` (3 миллиарда параметров) слишком мала для надёжной работы с tool calling. Она не понимает, что задача выполнена после первого успешного вызова инструмента.

**Возможные решения:**
1. Переключиться на `qwen2.5-7b` или `qwen2.5-14b` — значительно лучше работают с tool calling (требуется больше RAM: ~8–16 ГБ).
2. Добавить в `Orchestrator` проверку: если один и тот же инструмент вызывается 2+ раза с похожими аргументами — прерывать цикл.
3. Комбинированный подход: ограничение повторных вызовов + увеличение `max_steps` для сложных задач + fallback-контент для заметок.

**Статус:** Пока оставлено как есть, проблема задокументирована.
