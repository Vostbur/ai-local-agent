# AI Local Agent

Локальный AI-агент для повседневных задач на CPU.

## Цель
Агент работает полностью локально и решает задачи:
- анализ локальных документов и создание новых документов по их подобию;
- ведение заметок;
- сортировка фотографий по содержимому.

## Ограничения
- Работа на CPU, без GPU.
- 16 ГБ ОЗУ.
- Локальная LLM через Ollama или llama.cpp.
- Данные не отправляются в облако.

## Статус
Шаг 1: каркас проекта и документы. Код агента ещё не реализован.

## Структура
- `src/agent/` — код агента.
- `src/agent/tools/` — инструменты агента.
- `src/agent/memory/` — память и RAG.
- `tests/` — тесты.
- `data/` — локальные данные, не коммитятся.
- `logs/` — логи, не коммитятся.
- `config/` — настройки.
